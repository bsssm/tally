One turn, priced

First it reads the turn from the log.One JSON line per message in ~/.claude/projects. Sample turn.

Then it prices it at API rates.$10, $0.25 and $50 per million tokens: Anthropic's public rates, cache reads included.

Then it adds up 30 days.Each message counted once, however many lines it streamed.

Then it says what to do.No account, no telemetry, no upload.

One sentence, then levers

Under 80% of the plan price, the cheaper plan covers you. At or above it, keep the plan and see the multiple. Same thresholds as the CLI.

Max plans add a lever of their own: $100 or $200 a month of API credits that expire if you never claim them.

Two things it does for you

Credits router

Max plans include $100 to $200 of API credits a month, and they expire. Point your non-interactive jobs at a local endpoint and Tally spends the expiring credits first, then the cheapest paid route.

Output from this machine, 29 Oct 2026, against a fresh store with one declared pool.

Pacing for Claude Code

The 5-hour window burns fastest on the biggest model. The statusline shows the burn. Past 80%, a hook nudges effort down until the window resets.
